# KernelHub Studio · 界面设计规范（瑞士风格 / Swiss Style）

> 本文件是界面重构的**唯一依据**。实现前请完整读一遍，实现中遇到取舍也以本文件为准。
> 目标不是「好看一点」，而是**信息优先、结构清楚、按钮极少**。

---

## 0. 三条硬性约束（违反即返工）

1. **瑞士风格（International Typographic Style）**：网格、无衬线字、左对齐、大量留白、
   只用黑白灰 + 一个红点、**直角、无阴影、无渐变、无圆角卡片、无毛玻璃**。
2. **每屏可见按钮 ≤ 10 个**。
   计数口径：**屏幕上看得见的 `<button>` 元素**（含表格行里的操作按钮）；
   输入框、下拉框、勾选框、文字链、`role="button"` 的自定义元素不计入。
   → **列表类界面一律「整行可点」**（`<tr tabindex="0" role="button">` + hover 行背景变化 +
   行末一个非按钮的 `→` 提示），**不要每行放一个按钮**：
   18 行内核各放一个「详情」按钮，用户眼睛看到的就是 18 个按钮。
   整窗（含侧栏与窗口控制）另有一条 ≤ 20 的兜底上限。
3. **设置页参考 Chrome 设置架构**：左边一列分类导航，右边只显示当前分类的内容。
   详细配置（内核参数、命令行预览、内核详情、Schema 等）**必须收**进「高级」按钮里。

## 1. 设计令牌（重写 `styles/tokens.css`）

```
字体（无衬线，按可用性回退）
  --font-sans: "Helvetica Neue", Helvetica, Inter, "Segoe UI", Arial,
               "Microsoft YaHei UI", "Microsoft YaHei", sans-serif
  --font-mono: "SF Mono", "Cascadia Mono", Consolas, "Liberation Mono", monospace
  （标题与正文同族；粗细与字号拉开层级，不用装饰字体）

字号（固定 8 级，不许临时造新值）
  --fs-12 / --fs-13 / --fs-14 / --fs-16 / --fs-20 / --fs-28 / --fs-40
  层级约定：
    页面主标题 28（字重 400，轻微负字距 -0.01em）
    小节标题   16（字重 500）
    正文/表格  13
    次要说明   12
    大数字统计 40（字重 400，制表数字 font-variant-numeric: tabular-nums）

行高：--lh-tight 1.15 / --lh-snug 1.35 / --lh-normal 1.5

间距（8px 基准）
  --sp-1 4 / --sp-2 8 / --sp-3 12 / --sp-4 16 / --sp-5 24 / --sp-6 32 / --sp-7 48 / --sp-8 64

描边（结构靠 1px 细线，不靠阴影）
  --line: 1px solid var(--c-rule)

颜色 —— 浅色主题（默认）
  --c-paper     #ffffff   页面底
  --c-paper-2   #f4f4f4   分区底（表头、侧栏）
  --c-ink       #000000   主文字 / 主按钮底
  --c-ink-2     #555555   次要文字
  --c-ink-3     #8a8a8a   三级文字 / 占位
  --c-rule      #d8d8d8   分隔线
  --c-rule-2    #ebebeb   更弱的线
  --c-accent    #e8271b   唯一强调色（只用于：选中标记、错误、必须注意的数值）
  --c-ok        #1f7a3f
  --c-warn      #8a6d00
  --c-inverse   #ffffff   反白文字

颜色 —— 深色主题（[data-theme="dark"]）
  --c-paper     #101010
  --c-paper-2   #1a1a1a
  --c-ink       #ffffff
  --c-ink-2     #a8a8a8
  --c-ink-3     #6e6e6e
  --c-rule      #2e2e2e
  --c-rule-2    #232323
  --c-accent    #ff3b30
  --c-inverse   #101010

圆角：--r-0: 0（**所有卡片、按钮、输入框一律直角**；唯一例外：状态圆点用 50%）

动效：--t-fast 120ms / --t-base 180ms / --t-slow 260ms。
  缓动统一走缓进缓出：--e-in-out cubic-bezier(.4,0,.2,1)，进场用 --e-out。
  允许「颜色/背景/透明度」的过渡，以及**受约束的位移**（仅以下六类，幅度 ≤ 20px）：
    · 进度条宽度（--t-slow --e-in-out）
    · 分段选项卡指示条滑动（--t-slow --e-in-out）
    · 侧栏导航选中指示块滑动（--t-slow --e-in-out）
    · 通知卡片进出场（水平用 --d-slide = 20px，右侧滑入 / 滑出）
    · 通知堆叠让位（FLIP，--t-base）
    · 开启动画的字距收拢与进度线宽度
  一律禁止：缩放、回弹、发光、渐变流动、超过 20px 的位移。
  所有动效必须能被 `prefers-reduced-motion: reduce` 关掉（CSS 里统一压到 1ms 并
  停用 animation；JS 里用 matchMedia 判断后跳过）。
```

**绝对禁止**：`box-shadow`、`border-radius`（除状态点）、`linear-gradient`、
`backdrop-filter`、`transform: scale()` 反馈、彩色按钮（除主按钮是黑底/白字的反白块）。

> 关于位移的修订（2.0.3 起）：原规则是「只允许颜色/背景/透明度，禁止位移」。
> 实际用下来，进度条与选项卡选中反馈只靠颜色过渡会显得「跳」，通知堆叠时
> 剩余卡片会瞬移。因此在上面这些场景里放宽到允许受约束的位移，
> 幅度与时长都有上界，仍然不引入阴影 / 圆角 / 缩放这套语言。
> 2.0.4 追加：侧栏导航指示块、通知从右侧滑入、开启动画。

```
│ …            │  一句话说明（13px，--c-ink-2，最多 1 行）         │
│ 底部状态行     │  ── 1px 分隔线 ──                               │
│              │  工具栏（按钮 ≤ 10 个，左对齐，间距 --sp-2）        │
│              │  内容区                                         │
└──────────────┴────────────────────────────────────────────────┘
```

* 内容区用 **12 栏网格**（列间距 --sp-5），关键区块按栏对齐：
  两栏布局 = 4/8 或 5/7，不要 50/50。
* 表格：行高 40px、表头 12px 大写 --c-ink-3、单元格左对齐、
  数字右对齐（tabular-nums）、行分隔用 1px --c-rule-2，**不要斑马纹**。
* 空状态：一句话 + 一个主按钮，居中偏左，不要插画。
* 侧栏导航项：`01 转换` `02 队列` `03 内核` `04 格式` `05 协议` `06 日志`
  （编号用 --c-ink-3 等宽字，选中项：黑底反白块或左侧 2px 红条 + 黑字加粗，二选一，全站统一）。

## 3. 组件（重写 `styles/components.css`）

| 组件 | 规格 |
|---|---|
| `.btn` | 高度 32，内边距 0 12，1px 描边，透明底，13px；hover 背景 --c-paper-2；focus 2px 外描边 --c-ink |
| `.btn--primary` | 黑底反白，无描边；hover 背景 #222（深色主题 #e6e6e6） |
| `.btn--danger` | 描边 --c-accent，文字 --c-accent |
| `.btn--quiet` | 无描边无底色，只有文字与下划线（用于第三级操作） |
| `.input / .select` | 高度 32，1px 描边，直角，内边距 0 10；focus 描边变 --c-ink |
| `.label` | 12px，--c-ink-2，显示在输入框上方 6px |
| `.field` | 标签 + 控件 + 12px 说明，垂直间距 --sp-2 |
| `.table` | 见第 2 节 |
| `.badge` | 12px，1px 描边，内边距 0 6，高 20；状态用文字 + 前置 6px 方块（不圆点） |
| `.progress` | 高 6px 的实心条（--c-ink 填充 / --c-rule-2 轨道），不要动画条纹；宽度过渡缓进缓出，进度未知时用透明度呼吸（`.progress--indeterminate`） |
| `.segmented` | 分段选项卡：直角描边容器 + 一块实心指示条，指示条随选中项滑动（--t-slow --e-in-out）；选中项文字反白 |
| `.nav__indicator` | 侧栏选中指示块：与分段选项卡同源，方向竖直；导航项自身只改文字颜色，不换背景 |
| `.splash` | 开启动画：满屏纯 --c-paper + 居中的字标（字距收拢后淡入）+ 1px 细线 + 底部进度线。6 秒纯 CSS 兜底淡出 |
| `.statusbar__info` | 右下角实时信息：由当前视图通过 `ctx.setStatusInfo()` 推上来，用 · 分隔；超长省略不换行 |
| `.sheet`（高级面板） | 右侧抽屉或居中面板，白底、1px 描边、**无阴影**，标题 20px，右上角一个「关闭」文字按钮 |
| `.stat` | 大数字 40 + 下方 12px 标签，用于统计；不要图标、不要卡片边框，只用 1px 顶线 |

**图标**：仅用于按钮（16px，stroke 1.5，currentColor）与状态；不用于装饰性插画。
按钮若只有图标，必须有 `aria-label` 与 `title`。

## 5. 交互与状态

* **命令面板**：`Ctrl/Cmd + K` 打开居中面板，纯文字列表过滤，回车执行。
  可执行项：切换 6 个视图、开始转换、添加文件、清空列表、刷新内核、切换主题、打开高级、复制自检报告。
  样式同样瑞士：白底、1px 描边、无阴影、行高 36。
* **快捷键**：`Ctrl+1..6` 切视图、`Ctrl+O` 添加文件、`Ctrl+Enter` 开始转换、`Esc` 关闭面板、
  `Ctrl+K` 命令面板。侧栏导航项右侧显示编号数字（01–06）。
* **空状态**：每个视图都要有；文案一句话 + 最多一个主操作。
* **加载态**：骨架 = 灰底块（--c-rule-2），不要动画条纹，最多 120ms 透明度过渡。
* **错误态**：视图级错误用一整行：红条（--c-accent 底、反白字）+ 重试文字按钮。
* **主题切换**：`<html data-theme="light|dark">`，默认 `light`（瑞士风格以白底为主）。
  切换入口在顶栏（一个图标按钮）与设置页。写入 `khs.settings.set({ theme })`。
* **Toast**：右下角，白底 1px 描边、无阴影、直角，3 秒自动消失；同时写入日志。

## 6. 必须保留的功能（不能因为简化丢掉）

* 由 `ParamSpec` 生成参数控件（`int/float/bool/string/enum/path/color` 七种全支持）、
  `advanced` 折叠、`when` / `applies_to` 显隐、复位默认值 → 全部在「高级」面板里。
* 真实命令行预览（`plan.preview`）。
* 作业日志展开、产物定位、重试、取消、并发调整、暂停队列。
* 内核启停、优先级、详情（能力矩阵 / 参数表 / 依赖 / 安装命令 / 原始清单）。
* 格式矩阵的输入输出可达关系。
* 协议 Markdown 安全渲染（先转义再替换）+ 三份 Schema。
* 运行日志的过滤、清空、复制。
* 设置页全部字段（见 4.7）。
* 事件订阅：`evt:job:update`、`evt:job:log`、`evt:job:finish`、`evt:queue`、
  `evt:queue:enqueue`、`evt:queue:idle`、`evt:log`、`evt:window`、`cmd`。
* 拖拽投放文件（走 `ctx.pathForFile`）、`Ctrl+K`、`Ctrl+1..6`、`Ctrl+O`、`Ctrl+Enter`。
* 无 `window.khs` 时显示「请在 Electron 中运行」提示页（`boot.js` 机制不要动）。

## 7. 需要新增的测试钩子（供验收脚本使用）

```js
window.__khsTest = {
```

`visibleButtons()` 要过滤掉：`hidden`、`display:none`、`visibility:hidden`、
以及宽高为 0 的元素；返回 `innerText.trim()`（空则用 `aria-label`）。
